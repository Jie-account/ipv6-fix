# 使用说明

## 检查与修复

1. 从 [GitHub Releases](https://github.com/Jie-account/ipv6-fix/releases/latest) 下载便携包，解压到可写目录。
2. 双击 `IPv6修复工具.exe`，允许 Windows 管理员授权。
3. 点击“检查并修复 IPv6”，等待结果。当前正常时保持设置；满足重复对照条件时，自动排除失效旧源地址并复测。

也可以点击“仅检查”，只获取诊断结果。工具按需运行，不安装后台任务。

## 结果与恢复

| 结果 | 含义 |
|---|---|
| 当前 IPv6 连接正常 | 默认访问通过，没有修改设置 |
| 默认路径与源地址检查通过 | 默认路径和绑定公网源地址的连接均通过；TUN 开启时仍可能接管流量 |
| 默认路径可用，原生 IPv6 尚未验证 | 默认访问通过，公网源地址未全部通过；可临时退出 TUN 后对照检查 |
| 源地址可达，默认路径异常 | 公网源地址成功而默认连接失败，优先检查 TUN 路由或代理状态 |
| IPv6 已恢复 | 已处理确认失效的旧源地址，默认访问重复复测通过 |
| 未确认旧源地址故障 | 存在连接异常，但不符合此类修复条件，保持原状 |
| 未发现可用的 IPv6 地址或路由 | 需要检查网络接入、地址分配或路由问题 |
| 修复复测未通过 | 本次修改会自动还原，详情保存在记录中 |
| 需要检查部分修改 | 还原存在未完成项，使用记录和恢复按钮继续处理 |

“恢复上次修改”仅恢复本客户端最近一次修改的原值。恢复可能让尚未过期的旧地址重新参与选择。已自然消失的地址会跳过，不会重新创建。

“停止”会结束检查；若已开始修改，会先尝试还原本次原值。关闭忙碌窗口也会先执行停止和保存流程。

## 记录在哪里

记录优先保存在程序旁的 `Logs` 目录。位置只读时，使用当前用户的 `%LOCALAPPDATA%\IPv6Repair\Logs`。

点击“打开记录”查看最近操作的目录：`result.txt` 是可读摘要，`result.json` 是完整结果，`before.json` 和 `after.json` 保存地址/路由快照。`State/transactions` 保存恢复原值所需的记录。携带程序时，若需要保留修复历史，也应保留 `Logs`。

诊断记录包含本机网络地址，分享前请按需要处理其中的信息。程序不会主动上传记录。

## 自动修复的条件

测试目标的 IPv6 地址会在每轮检查时解析并固定，所有连接绕过应用代理。对同一固定目标，默认连接与某个旧前缀源地址连续两轮连接失败，同时另一个前缀的源地址连续成功，才产生修复计划。写入前复核地址和路由，保存原值后仅设置失效地址的 `SkipAsSource=true`，不删除地址，不重启网卡，不改默认路由。

修改后的默认连接连续复测通过才显示成功；中途失败则恢复原值。证书/TLS 错误、只有一轮波动、所有源地址都失败，以及同一前缀中的问题不会套用这个修复。

这是一类问题的恢复工具。长期根治仍需纠正新旧前缀退役机制；新的失效前缀再次产生时，仍可能需要重新检测。

### TUN、虚拟网卡与合成 DNS

v1.0.2 分别记录默认路径和公网地址所在网卡。Mihomo 等 TUN 只有 ULA 地址时，工具继续检查 WLAN 等接口上的公网地址。默认路径经过虚拟或其他接口时，仅诊断并保留地址设置；需要进一步验证原生网络时，可临时退出 TUN 后再次检查。

绕过应用代理的选项不会绕过 TUN。绑定公网源地址的成功结果会核对实际本地地址，但 TUN 仍可能接管流量，因此工具反馈具体路径，不以代理访问成功证明原生 IPv6 正常。

当系统只返回 `2001:2::/48` 等合成或非公网地址时，工具通过阿里 DNS 的 HTTPS 接口为两个固定测试域名获取真实 AAAA 地址。本次解析与原始系统解析均保存到 `targets.json`；解析失败时报告检查不完整，不修改系统 DNS。

`before.json`、`after.json` 同时保存所有网卡的地址状态与默认路由。再次故障时先运行“仅检查”并保留这组记录，再按结果处理，有助于区分地址缺失、旧前缀残留和 TUN 路径异常。

## 显示与测试

v1.0.1 使用明确的 96 DPI 设计基准，标题、状态和说明按内容计算行高。长提示会换行，大字号内容超过窗口时可以滚动，操作按钮在窄窗口自动换行。

布局测试在当前系统 DPI 下额外放大文字至 100%、125%、150%、200%，覆盖初始、修复结果、长提示及紧凑窗口；同时检查文字测量、父容器裁切和区块重叠。网络逻辑测试使用标准文档地址 `2001:db8::/32` 的合成样例，不依赖个人网络抓包。
